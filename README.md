# Supply Chain & Inventory Analysis

## Project Overview

This project analyzes supply chain and inventory data using Python and Pandas to identify key business trends, product profitability, supplier performance, regional performance, delivery status, and inventory issues.

The analysis helps understand sales performance, profitability, inventory levels, and operational efficiency.

## Objectives

- Analyze product and category performance
- Identify the most profitable products
- Analyze regional sales and profitability
- Evaluate supplier performance
- Identify low-stock products
- Analyze delivery performance
- Study monthly sales trends
- Evaluate fulfillment rate, defect rate, and lead time

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter/VS Code

## Data Cleaning

The dataset was cleaned using the following steps:

- Checked missing values
- Filled missing Supplier values using the mode
- Filled missing Lead Time values using the median
- Filled missing Defect Rate values using the median
- Converted Order Date into datetime format
- Checked and removed duplicate records

## Key Business Insights

- Mouse was identified as the most profitable product.
- Electronics was the best-performing product category by revenue.
- West was the most profitable region.
- Supplier B was the best-performing supplier by profit.
- On Time was the most common delivery status.
- 295 low-stock records were identified, indicating a need for better inventory monitoring and timely replenishment.

## Business Recommendations

- Focus on high-profit products such as Mouse.
- Prioritize Electronics for inventory and sales planning.
- Maintain and strengthen performance in the West region.
- Use Supplier B's performance as a benchmark for supplier evaluation.
- Improve inventory monitoring to reduce low-stock situations.
- Continue monitoring delivery performance to maintain on-time deliveries.

## Conclusion

The analysis provides useful insights into supply chain performance, profitability, supplier efficiency, regional performance, and inventory management.

The findings can help businesses make better decisions related to inventory replenishment, supplier management, product prioritization, and operational efficiency.
